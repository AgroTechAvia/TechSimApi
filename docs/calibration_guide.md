# Практическая инструкция по калибровке

Эта инструкция описывает штатный интерфейс установленного пакета
`agrotechsimapi`. Скрипты из `utils` нужны только для совместимости со старыми
запусками.

## 1. Подготовка

Установите пакет и убедитесь, что симулятор запущен, дрон установлен на свободном
участке карты, а RPC и MSP доступны на настроенных портах.

```bash
python -m pip install agrotechsimapi
python -m agrotechsimapi calibrations list
```

При установке из репозитория используйте `python -m pip install .`. В режиме
разработки удобнее `python -m pip install -e .`.

Пакет содержит три встроенных пресета:

- `edu-ext` — профиль по умолчанию;
- `edu-constructor`;
- `edu`.

Встроенные профили доступны только для чтения. Имя `default` оставлено как
псевдоним `edu-ext` для старого кода.

## 2. Создание конфигурации

```bash
python -m agrotechsimapi calibrations init-config --output calibration.json
```

Команда создаёт полный JSON с актуальными настройками. Чаще всего перед запуском
достаточно проверить:

- `host`, `sim_port`, `msp_port` — адрес и порты;
- `drone_name` — модель дрона;
- `hover_height` — высота испытаний yaw и XY относительно высоты в начале сессии;
- `direction` — направления pitch, roll и yaw;
- ограничения скорости, ускорения и PWM;
- параметры ручного продолжения и возврата после падения.

Не используйте старый конфигурационный файл после обновления алгоритма без
сравнения с новым: неизвестные или отсутствующие параметры могут сделать запуск
невоспроизводимым.

## 3. Проверка плана без полёта

Без `--fly` команда выводит итоговую конфигурацию и этапы, но не подключается к
симулятору:

```bash
python -m agrotechsimapi calibrate --name my_drone --config calibration.json
```

По умолчанию начальные коэффициенты и уже настроенные внешние контуры берутся из
`edu-ext`. Другую основу можно выбрать явно:

```bash
python -m agrotechsimapi calibrate --name my_drone --base edu --config calibration.json
```

Имя новой калибровки должно отличаться от имён встроенных пресетов.

## 4. Полная калибровка

```bash
python -m agrotechsimapi calibrate --name my_drone --config calibration.json --fly
```

Этапы выполняются последовательно:

1. высота;
2. yaw;
3. ускорение XY;
4. скорость XY;
5. положение XY.

Каждый следующий этап использует уже найденные коэффициенты предыдущих. Контуры,
которые ещё не настроены и не нужны текущей пробе, отключаются.

Профиль публикуется только после завершения всех запрошенных этапов. Статус
`needs_review` означает, что пригодный лучший набор сохранён, но одна из итоговых
проверок не выполнила желаемый допуск. Прерванная или незавершённая сессия не
заменяет существующий профиль с тем же именем.

Чтобы заменить ранее сохранённую пользовательскую калибровку после успешного
завершения, добавьте `--replace`:

```bash
python -m agrotechsimapi calibrate --name my_drone --config calibration.json --fly --replace
```

## 5. Калибровка отдельного этапа

Доступные значения `--stage`: `height`, `yaw`, `acceleration`, `velocity`,
`position`.

```bash
python -m agrotechsimapi calibrate \
  --name my_velocity \
  --base my_drone \
  --stage velocity \
  --config calibration.json \
  --fly
```

`--base` особенно важен для отдельного этапа: из него загружаются все контуры,
которые к этому моменту уже должны быть настроены.

## 6. Что делать после падения или ручного возврата

Калибратор не принимает прерванную пробу за измеренный результат. Если дрон упал,
перевернулся или оказался вне рабочей зоны, система ждёт возврата. Установите дрон
на землю в безопасном месте. Посадка определяется по устойчивой околонулевой
вертикальной скорости; абсолютная координата Z не обязана совпадать с начальной.

Если автоматическое распознавание не сработало за заданное время, терминал
предложит ручное продолжение. После установки дрона нажмите Enter: текущая проба
будет повторена. Ctrl+C завершает сессию, сохраняя сырую телеметрию для анализа.

На этапе высоты цель каждого нового взлёта строится относительно фактической
высоты земли перед этим взлётом. На этапах yaw и XY рабочая высота остаётся
относительной к положению в начале всей сессии.

## 7. Графики текущей калибровки

Создать одноразовый снимок уже записанных проб последней сессии:

```bash
python -m agrotechsimapi plot --current --open
```

Показать только последние восемь проб каждого этапа:

```bash
python -m agrotechsimapi plot --current --last 8 --open
```

Команда не обновляет страницу автоматически. Повторите её, когда нужен свежий
снимок. Без `--open` путь к HTML выводится в терминал.

## 8. Графики завершённой калибровки

```bash
python -m agrotechsimapi plot --calibration my_drone --open
```

Сохранить отчёт в выбранное место и открыть его сначала на английском:

```bash
python -m agrotechsimapi plot \
  --calibration my_drone \
  --output my_drone_report.html \
  --lang en \
  --open
```

HTML автономен: CSS и JavaScript встроены в файл. Его можно передать вместе с
экспортированным JSON. В отчёте есть вкладки высоты, yaw, ускорения, скорости и
положения, а также переключатель RU/EN.

Для анализа старого каталога запуска:

```bash
python -m agrotechsimapi plot --run PATH_TO_RUN --output legacy_report.html
```

## 9. Просмотр, экспорт и импорт

```bash
python -m agrotechsimapi calibrations list
python -m agrotechsimapi calibrations show my_drone
python -m agrotechsimapi calibrations export my_drone --output my_drone.json
python -m agrotechsimapi calibrations import my_drone.json --name imported_drone
```

Если пользовательское имя уже существует, для осознанной замены добавьте
`--replace`. Встроенные профили заменить нельзя.

## 10. Использование результата в клиенте

```python
from agrotechsimapi import HighLevelClient

client = HighLevelClient(calibration="my_drone")
```

Переносимый JSON можно использовать без импорта:

```python
client = HighLevelClient(calibration_path="my_drone.json")
```

Отдельные параметры PID, переданные конструктору клиента, имеют приоритет над
выбранным профилем.

## 11. Где сохраняются данные

| ОС | Каталог |
|---|---|
| Windows | `%LOCALAPPDATA%\agrotechsimapi` |
| Linux | `$XDG_DATA_HOME/agrotechsimapi` или `~/.local/share/agrotechsimapi` |
| macOS | `~/Library/Application Support/agrotechsimapi` |

Переменная `AGROTECHSIMAPI_DATA_DIR` меняет каталог для всех команд. Разово
указать другое хранилище можно глобальным аргументом перед подкомандой:

```bash
python -m agrotechsimapi --data-dir D:\calibrations calibrations list
```

Основные подкаталоги:

```text
calibrations/   завершённые именованные профили
runs/           CSV, summary.json и состояние сессий
reports/        созданные HTML-отчёты
active.json     указатель на последнюю сессию
```

## 12. Диагностика

- **Команда только напечатала JSON и завершилась:** добавьте `--fly`.
- **Профиль отсутствует после Ctrl+C:** незавершённые профили намеренно не
  публикуются; телеметрия остаётся в `runs`.
- **График текущей сессии не меняется:** повторно выполните `plot --current`.
- **Нужный профиль не найден:** проверьте `calibrations list`, активное окружение,
  `AGROTECHSIMAPI_DATA_DIR` и аргумент `--data-dir`.
- **После изменения исходников поведение старое:** переустановите пакет или
  используйте editable-установку.

Подробные критерии отдельных регуляторов и внутренний формат профиля описаны в
[технической документации](calibration.md).
